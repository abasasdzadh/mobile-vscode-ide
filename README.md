# 🚀 Mobile VS Code IDE

A powerful mobile-friendly web IDE inspired by Visual Studio Code.

This project provides a complete coding environment directly inside the browser, allowing users to write, edit, preview, and run code on mobile devices without installing heavy software.

---

✨ Features

- 📝 Monaco Editor (VS Code Editor)
- 🐍 Python execution using Pyodide
- ⚡ JavaScript execution
- 🌐 Live HTML Preview
- 📱 Fully Responsive Mobile UI
- 🌙 Dark & Light Theme
- 📂 File Manager
- ✏️ Rename/Delete/Create Files
- 📥 Import Files
- 📤 Export Files
- ⌨️ Mobile Keyboard Helper Bar
- 🖥️ Fullscreen HTML Preview
- 📦 Python Package Installation (micropip)
- 💾 Local Storage Auto Save

---

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Monaco Editor
- Pyodide
- Font Awesome
